\begin{abstract}
Writing radiology reports is a slow and difficult task for doctors. Artificial Intelligence (AI) can help, but current models often make mistakes. They can "hallucinate" diseases that are not there, and they often sound confident even when they are wrong. Also, models trained at one hospital often fail when used at a different hospital. This research proposes a new system to fix these problems. We improve the R2Gen architecture by adding two features: (1) a "fact-checker" using Knowledge Graphs (RadGraph) to reward the model for being medically correct, and (2) an uncertainty system (Monte Carlo Dropout) that lets the model say "I am not sure." We will test this system on four large public datasets to ensure it works well in different situations.
\end{abstract}

\section{Introduction}

\subsection{Motivation}
The number of medical images taken every year is growing by 5-10\%, but there are not enough radiologists to read them. This causes burnout and leads to errors in about 3-5\% of cases. Current AI tools usually give a simple "Yes/No" diagnosis, which is not enough for doctors who need explanations. Vision-Language Models (VLMs) can write full reports, but they have a major flaw: they prioritize grammar over truth. They might write a sentence that looks perfect but describes a lung problem on the wrong side. Furthermore, we do not know when to trust these models because they do not provide a confidence score.

\subsection{Research Objectives}
This project aims to build a safer, more reliable AI for radiology. We have three main goals:
\begin{enumerate}
    \item \textbf{Measure Uncertainty:} Use a technique called Monte Carlo Dropout to estimate how unsure the model is. This helps identify difficult cases that need a human doctor.
    \item \textbf{Improve Factuality:} Change the training process so the model is punished for hallucinating medical facts, rather than just matching words.
    \item \textbf{Test Robustness:} Evaluate the model on datasets from different hospitals to see if it generalizes well to new data.
\end{enumerate}

\section{Baselines}
To measure our success, we will compare our model against these standard methods:

\begin{itemize}
    \item \textbf{R2Gen (Chen et al., 2020) \cite{chen2020r2gen}:} This is a popular model for generating reports. It uses a "memory" component to remember common sentence patterns. However, it does not check if the medical facts are true.
    \item \textbf{CheXzero (Tiu et al., 2022) \cite{tiu2022chexzero}:} This is the best model for "zero-shot" classification (identifying diseases without seeing them during training). It is good at detection but cannot write full reports.
    \item \textbf{MedCLIP (Wang et al., 2022) \cite{wang2022medclip}:} This model separates image and text learning, which helps it learn from larger datasets. We use this to see how well standard contrastive learning works.
\end{itemize}

    \item \textbf{CheXpert (Stanford):}
    \begin{itemize}
        \item \textbf{Details:} 224,316 images from 65,240 patients.

    \end{itemize}
    
    \item \textbf{PadChest (Spain):}
    \begin{itemize}
        \item \textbf{Details:} 160,000 images with reports in Spanish.
        \item \textbf{Importance:} Used to test if the visual features learned by the model work across different populations and equipment types.
    \end{itemize}

\subsection{Preprocessing Steps}
Before training, we will standardize the data:
\begin{itemize}
    \item \textbf{Resizing:} All images will be resized to $224 \times 224$ pixels to fit the ResNet encoder.
    \item \textbf{Normalization:} We will normalize pixel intensity to have a mean of 0 and standard deviation of 1.
    \item \textbf{Text Cleaning:} All reports will be converted to lowercase. We will remove non-medical information (like patient names) and remove very rare words that appear less than 3 times.
\end{itemize}

\subsection{Evaluation Metrics}
We will move beyond standard NLP metrics to clinical relevance metrics:
\begin{itemize}
    \item \textbf{RadGraph F1:} Measures if the correct clinical facts were reported.
    \item \textbf{AUROC:} Measures classification accuracy.
    \item \textbf{ECE (Expected Calibration Error):} Measures if the model's confidence matches its actual accuracy.
\end{itemize}

\section{Proposed Methodology}

\subsection{Method Overview}
Our approach improves the standard "Encoder-Decoder" model. The Encoder turns the X-ray image into a set of numbers (vectors). The Decoder translates those numbers into a text report. We add two main improvements to this structure.

\subsection{Improvement 1: Factuality Reward (Reinforcement Learning)}
Standard models try to match the exact words of the training reports. This is a problem because "No pneumonia" and "Mild pneumonia" are very similar in wording but opposite in meaning.

We propose using RadGraph, a tool that extracts medical entities (like "lung", "heart") and their status (like "normal", "enlarged"). 
\begin{itemize}
    \item We extract the graph from the \textit{Ground Truth} report ($G_{gt}$).
    \item We extract the graph from the \textit{Generated} report ($G_{pred}$).
    \item We calculate the F1-score overlap between these two graphs.
    \item This score is used as a Reward to train the model. If the model gets the medical facts right, it gets a high reward, even if the wording is slightly different.
\end{itemize}

\subsection{Improvement 2: Uncertainty Estimation (Monte Carlo Dropout)}
Deep learning models are usually deterministic (they give the same answer every time). To measure uncertainty, we use Monte Carlo (MC) Dropout.
\begin{itemize}
    \item During training, we randomly turn off some neurons (Dropout) to prevent overfitting.
    \item Usually, we turn Dropout \textit{off} during testing.
    \item \textbf{Our Method:} We keep Dropout \textit{on} during testing. We run the same image through the model $T$ times (e.g., 10 times).
    \item If the model generates the same report 10 times, it is Confident.
    \item If the model generates 10 very different reports, it is Uncertain. The variance of these outputs gives us a reliability score.
\end{itemize}

\subsection{Theoretical Formulation}
The total loss function ($\mathcal{L}_{total}$) combines language fluency and clinical accuracy:

\begin{equation}
    \mathcal{L}_{total} = \underbrace{\mathcal{L}_{CE}}_{\text{Fluency}} + \lambda \cdot \underbrace{\mathcal{L}_{Fact}}_{\text{Accuracy}}
\end{equation}

Where:
\begin{itemize}
    \item $\mathcal{L}_{CE}$ is the standard Cross-Entropy loss (predicting the next word).
    \item $\mathcal{L}_{Fact}$ is the Reinforcement Learning loss based on RadGraph F1-score.
    \item $\lambda$ is a weight parameter. We start with $\lambda=0$ and slowly increase it during training to stabilize learning.
\end{itemize}

Our core contribution is a hybrid loss function that balances linguistic fluency with clinical truth.

\textbf{1. Epistemic Uncertainty via Bayesian Approximation:}
We model the neural network as a probabilistic function $p(y|x, \theta)$. Instead of a point estimate, we approximate the posterior distribution $p(\theta|D)$ using Monte Carlo (MC) Dropout. During inference, we perform $T$ stochastic forward passes.
The predictive uncertainty is quantified by the variance of the outputs:
\begin{equation}
    \text{Var}(y) \approx \frac{1}{T} \sum_{t=1}^{T} (\hat{y}_t - \bar{y})^2 + \frac{1}{T} \sum_{t=1}^{T} \sigma_t^2
\end{equation}
where $\hat{y}_t$ is the prediction of the $t$-th pass and $\sigma_t^2$ is the inherent observation noise.

\textbf{2. Factuality-Constrained Optimization:}
Let $G_{gt}$ be the Knowledge Graph extracted from the ground truth report, and $G_{pred}$ be the graph from the generated report. We define a reward function $R$ based on the graph overlap (Precision/Recall of clinical entities).
The final loss function $\mathcal{L}_{total}$ combines Cross-Entropy (CE) loss with a Policy Gradient (RL) loss:
\begin{equation}
    \mathcal{L}_{total} = \underbrace{-\sum \log p(y_t|y_{<t}, x)}_{\text{Linguistic Fluency}} + \lambda \underbrace{\mathbb{E}_{\hat{y} \sim p_\theta} [1 - \text{F1}_{\text{RadGraph}}(G_{pred}, G_{gt})]}_{\text{Clinical Factuality}}
\end{equation}
where $\lambda$ is a hyperparameter balancing fluency and factuality.

\subsection{Implementation Steps}

\begin{algorithm}[H]
\SetAlgoLined
\DontPrintSemicolon
\KwInput{Images $\mathcal{X}$, Real Reports $\mathcal{Y}$}
\KwOutput{Trained Model $\theta$}

\textbf{1. Setup:} Load Pre-trained ResNet and BERT tokenizer\;

\While{Training is not done}{
    \textbf{2. Forward Pass:}\;
    Get image features $v = \text{Encoder}(x)$\;
    Generate text report $\hat{y} = \text{Decoder}(v)$\;
    
    \textbf{3. Calculate Language Loss:}\;
    Compare words of $\hat{y}$ and $y$ (Cross Entropy Loss)\;
    
    \textbf{4. Calculate Fact Loss (RL):}\;
    Extract facts: $G_{pred} = \text{RadGraph}(\hat{y})$\;
    Extract facts: $G_{real} = \text{RadGraph}(y)$\;
    Calculate Reward = F1 Score between $G_{pred}$ and $G_{real}$\;
    
    \textbf{5. Update Model:}\;
    Adjust weights $\theta$ to maximize Reward and minimize Language Loss\;
}
\textbf{6. Testing (Uncertainty):}\;
Run image $T$ times with Dropout ON\;
Calculate variance of outputs to measure confidence\;

\caption{Training and Testing Logic}
\end{algorithm}

\section{Conclusion}
